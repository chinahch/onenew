# Onenew 节点安装接入

目标：将服务器管理生成的上游安装命令接到自有的、经过校验的二进制发布包。参考 chinahch/php-fpm-core 的机器安装模式和既有双 IP 定制，不执行附件脚本，不覆盖该仓库已有构建。

- [x] 安装命令回归：面板、机器 ID、令牌正确引用，自有 URL，root 无需 sudo。固定控制器补丁已在独立副本应用并通过 PHP 语法检查。
- [x] 自有安装器：HTTPS、架构检查、SHA256、版本核验、私有配置、systemd/OpenRC；现有安装拒绝覆盖。离线安装器三项、打包器两项测试通过。
- [x] 固定既有定制源码，加上已验证的域名元数据和运行时品牌补丁，接入 amd64/arm64 发布流程。原生双内核/机器测试、本地 amd64 交叉构建通过；公开 CI 和 Release 验证待完成。
- [ ] 原生测试与安装器回归通过后发布包；验证面板构建与生成命令，再给出部署步骤。

按用户最新要求，安装使用 /etc/caddy、caddy.service、/usr/local/bin/caddy 和 caddyctl，进程名仍为 caddy。旧 caddy、php-fpm 和 xboard-node 安装保留；迁移需要先备份并停止旧服务，不将自动安装当作无损在线迁移。跨架构编译通过不等于 ARM64 低内存服务器实测通过。
