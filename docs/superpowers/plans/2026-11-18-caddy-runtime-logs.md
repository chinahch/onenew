# Caddy runtime log collection

User authorizes full runtime diagnostic collection excluding ALL XB user/node-port configuration push/success information. No existing historical journal export: collect from filtered logger before stdout/file and before upload, so banned lines never reach new local logs. Preserve error reason but redact user/node IDs, addresses, ports, credentials; suppress successful config snapshots/users/listener success events. Systemd/OpenRC compatible by internal logger capture, no arbitrary shell/journal scraping.

Implement bounded asynchronous batching authenticated by current machine credential, deployment/machine identity-bound sequence/dedup cursor, backpressure/retention and explicit dropped-count reporting; cannot promise infinite/full history. Default7days panel retention, max1000lines/256KB batch, 10second delivery, small bounded memory buffer. UI machine detail runtime log panel with date/severity/search pagination; AI native read safe bounded log query. Panel auth admin-only, machine credential scoped upload, current machine identity prevents recycledID inheritance. All secrets redacted on node and rechecked on panel. No raw dump/URL body/credentials sent AI. Backend migrations auto startup. New node release required; old node state clearly upgrade_required.
